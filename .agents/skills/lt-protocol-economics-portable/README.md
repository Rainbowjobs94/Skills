# LT Protocol and Economics Reconciliation

Portable skill package for building a source-grounded register of Love
Transcends protocols and token economics, comparing it with current software,
reviewing a task backlog, and preparing a project-to-project handoff.

## Files

- `SKILL.md` — reusable workflow and evidence/safety rules.
- `references/local-lt-source-snapshot.md` — bounded source observations from the
  project where this package was prepared. It is not a canonical specification.
- `templates/protocol-economics-ledger.md` — blank ledger template.
- `project-review/` in the expanded ZIP — dated local protocol reconciliation and
  provisional backlog review. These are project-specific examples, not portable
  defaults or a complete audit.

## Import

Copy the `lt-protocol-economics-portable` directory into the destination agent’s
supported skills directory and register/enable it using that host’s current
instructions. On a new project, do not use the local snapshot as fact; inventory
the destination’s code, specifications, tests, deployment evidence, and task
queue, then generate a new project adapter.

A copied skill is not automatically installed, authorized, or executable on
another host. It grants no credentials, provider budget, legal rights, deployment
authority, or financial permissions.

## Package status

The local source snapshot enumerates local contract files and records selected
core-contract findings. The companion review enumerates visible local task
priorities, but the task queue snapshot was incomplete. Neither review is a
complete audit or certification of every protocol, deployment, economic claim,
or task.
